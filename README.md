# Catalogo web Siempre Natural

Este sitio es un archivo estatico, sin build ni dependencias. `index.html` incluye la lista, el logo, el carrito y el enlace de WhatsApp.

Para GitHub Pages, usa un repositorio publico y publica desde la rama principal, carpeta raiz. El archivo de entrada debe llamarse `index.html`.

Los productos marcados como "No disponible" permanecen visibles, pero no se pueden agregar al pedido.
